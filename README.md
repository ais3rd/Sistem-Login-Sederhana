# Sistem Login Sederhana

A simple console login system in C that keeps asking for a username and password until they match. The interface is in Bahasa Indonesia.

## Demo account
| Username | Password |
|---|---|
| `praktikan` | `1234` |

## Concepts practiced
- Global character arrays and `scanf`
- String comparison with `strcmp`
- `while` loops and helper functions

## Build and run
The project file is for Code::Blocks (`Sistem Login.cbp`). You can also build it with GCC:

```bash
gcc main.c -o login.exe
login.exe
```

> This is a learning exercise. The credentials are hard-coded and aren't secure.
